# csv-to-insights-dashboard
A zero-login, privacy-first browser dashboard that turns raw CSV files into animated charts, data-health metrics, and plain-English insights locally in seconds.

CSV files are processed in the browser and are not uploaded by the app. CSV text is escaped before display, and formula-like values are neutralized in downloaded files. Tailwind CSS and Chart.js scripts are version-pinned with Subresource Integrity; Google Fonts and the pinned assets load over HTTPS, so their providers receive standard connection metadata.
